### 关键设计决策

1. **BLE 写入序列化**：`Completer<void> _writeLock` 确保同时只有一个 BLE write 操作
2. **滑块节流**：`_throttledSend(key, data, ms: 48)` — 48ms 窗口内合并连续写入，适配高刷滑动手感
3. **连接后自动查询**：`connect()` 成功后自动 `queryStatus()` 同步 FPGA 状态到 App
4. **非阻塞 BLE init**：`_initBLE()` 在 splash fade 后后台执行，不会阻塞 UI 10s
5. **queryStatus 竞态修复**：先通过 `BleRxParser.startStatusCollecting()` 进入收包状态并启动 timeout，再 `_send(0xFF)`；若状态帧前出现残留 ACK/ERR 会忽略，partial frame 计数用于 2s timeout 诊断
6. **手动 i18n**：`pubspec.yaml` 中 `generate: false`，手写 Dart localization 文件（不用 l10n.yaml）
7. **Scene tab debounce**：300ms Timer 防止快速点击导致 queryStatus 状态机错乱
8. **连接失败统一清理**：connect 前、失败分支和 catch 统一 `_teardownConnection()`，取消 notify/connection subscription，清空 `_device/_txChar` 并 reset parser
9. **FFF2 写入模式回退**：优先 `writeWithoutResponse`，若设备只暴露普通 `write` 则 fallback 到 `withoutResponse:false`，调试日志记录实际 write mode
10. **BLE 权限请求与错误分类**：扫描前请求 Android `bluetoothScan` + `bluetoothConnect`，连接前请求 `bluetoothConnect`；扫描、连接、自测和 TX 失败会通过 `_classifyBleError()` 识别 Android BLE/定位/附近设备权限问题，复制诊断快照时能看到可执行排查方向
11. **底栏滚动隐藏**：`MainShell` 统一监听 `UserScrollNotification`，在 `hideBarOnScroll` 开启时按滚动方向控制 `barVisibilityProvider`；视觉层使用 `AnimatedSlide + AnimatedOpacity` 平移淡出，不再用 `heightFactor` 瞬时压缩布局

### BLE 通信协议 (App ↔ FPGA via CH9143)

```
Service:  FFF0
Write:    FFF2 (APP → FPGA, writeWithoutResponse)
Notify:   FFF1 (FPGA → APP)

命令帧：
  0x10 R G B        → ACK: 0xAA/0xEE
  0x11 Brightness   → ACK: 0xAA/0xEE
  0x20 Mode         → ACK: 0xAA/0xEE
  0x21 FlowSpeed    → ACK: 0xAA/0xEE
  0x22 BreathPeriod → ACK: 0xAA/0xEE
  0x30 SceneSlot    → ACK: 0xAA/0xEE
  0x31 SceneSlot    → ACK: 0xAA/0xEE
  0xFF              → 5-byte: [Mode][R][G][B][Brightness]
```

## FPGA 工程结构

```
final-rgb-controller/
├── final-rgb-controller.qpf/qsf/sdc   # Quartus 工程
├── src/                                # 9 active Verilog modules
│   ├── rgb_controller_top.v            # 顶层集成
│   ├── cmd_parser.v                    # 6-state FSM, 命令解析+ACK
│   ├── uart_rx_byte.v                  # UART RX 115200
│   ├── uart_tx_byte.v                  # UART TX 115200
│   ├── ws2812_driver.v                 # WS2812 NRZ 编码, 8 LED
│   ├── breath_engine.v                 # 64-entry 正弦 LUT
│   ├── flow_engine.v                   # 单灯追逐
│   ├── gradient_engine.v               # 128-entry 彩虹 LUT
│   ├── scene_store.v                   # 8 slot 场景存储
│   └── rgb_pwm_core.v                  # legacy PWM reference, not compiled/instantiated
├── sim/
│   ├── tb_rgb_controller.v             # 18 full-link test cases
│   ├── tb_ws2812_driver.v              # WS2812 bit timing/reset regression
│   └── run.do                          # ModelSim 脚本
└── output_files/                       # .sof (gitignored)
```

### 引脚映射（已验证，不要改）

| Signal | Pin | Direction | Connects To |
|--------|-----|-----------|-------------|
| clk | PIN_E1 | In | 50 MHz oscillator |
| nrst | PIN_L2 | In | Active-low reset |
| rx_din | **PIN_B11** | In | CH9143 TX → FPGA RX |
| tx_dout | PIN_D6 | Out | FPGA TX → CH9143 RX |
| led_din | PIN_T2 | Out | WS2812 data |
| tx_en | PIN_K1 | In | Button (debug) |
| tx_busy_flag_qn | PIN_A7 | Out | Debug LED |

**警告**：不要用 PIN_D5 做 UART RX，那是早期接线错误。
